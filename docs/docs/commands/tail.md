# `tail`

Extracts the last N rows from a data file. Uses efficient buffering for large files.

Without `--output`, rows go to stdout in the input's text format (CSV in, CSV out; JSON Lines for binary inputs); `-O`/`--format-out` overrides it. With `--output`, the format follows the file extension. Use `-` as the input to read standard input.

```bash
# Last 10 rows (default) on stdout, in the input format
undatum tail data.csv

# Extract last 50 rows
undatum tail data.jsonl --limit 50

# Save to file (not a positional path)
undatum tail data.csv --limit 20 --output output.csv

# Named Excel sheet
undatum tail workbook.xlsx --table Sheet2 --limit 5

# Nested JSONL: unfold dict fields onto dotted paths
undatum tail nested.jsonl --flatten-nested --limit 5
```
