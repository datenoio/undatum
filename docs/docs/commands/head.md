# `head`

Extracts the first N rows from a data file. Useful for quick data inspection.

Without `--output`, rows go to stdout in the input's text format (CSV in, CSV out; JSON Lines for binary inputs); `-O`/`--format-out` overrides it. With `--output`, the format follows the file extension. Use `-` as the input to read standard input.

```bash
# First 10 rows (default) on stdout, in the input format
undatum head data.csv

# Extract first 20 rows
undatum head data.jsonl --limit 20

# CSV in, JSON Lines out
undatum head data.csv -n 5 -O jsonl

# Save to file (not a positional path)
undatum head data.csv --limit 5 --output output.csv

# Named Excel sheet
undatum head workbook.xlsx --table Sheet2 --limit 5

# Nested JSONL: unfold dict fields onto dotted paths
undatum head nested.jsonl --flatten-nested --limit 5

# First 3 rows matching a SQL condition
undatum head data.csv -n 3 --where "status = 'active'"
```
