# `transpose`

Swaps rows and columns: every input field becomes one output record with `field` (the
field name) and `row_0`, `row_1`, ... (its value in each input record). Fields keep their
order in the file. The input is read once per field, so memory holds one column at a time.

For an input

```text
name,age
Alice,34
Bob,28
```

the output is

```text
field,row_0,row_1
name,Alice,Bob
age,34,28
```

Write with `--output`. A trailing path is not a positional argument.

```bash
# Transpose CSV file
undatum transpose data.csv --output output.csv

# Transpose JSONL file
undatum transpose data.jsonl --output output.jsonl
```
